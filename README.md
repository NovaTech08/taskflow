# TaskFlow (by NovaTech)

About this project: TaskFlow is an enterprise task management application developed as a collaborative university project for the Systems Analysis program. 

## Project Objective & Development Workflow
While this project implements foundational C# backend logic, its primary objective was to simulate a real-world software development lifecycle. The team placed a strong emphasis on collaborative engineering practices, including:
* Version Control: Extensive use of Git and GitHub for branch management.
* Code Review: Utilizing Pull Requests (PRs) to ensure code quality and team consensus.
* Issue Tracking: Managing bugs and feature requests through GitHub Issues.
* Agile Methodology: Organizing tasks, sprints, and workflow states using Kanban boards.

## Current Status
Please note that this repository contains a foundational implementation focused on core application logic. While the academic objectives for this phase were successfully met, the system is not a fully finished product and currently operates exclusively via the command line, without a graphical user interface (frontend).

## Overview
TaskFlow provides a streamlined way to handle enterprise workflow through an interactive Command Line Interface (CLI). Users can efficiently create tasks, assign them to team members, update statuses, and query task lists in real-time.

## Key Features
* Task Management: Create new tasks and assign them to specific users.
* Status Tracking: Update and monitor task progress across three states: Pending, In Progress, and Completed.
* Data Querying: Retrieve and view organized lists of current tasks.
* Interactive CLI: A user-friendly console menu (options 1-6) exposing all core system functionalities.

## Tech Stack
* Language/Framework: C# / .NET
* Data Persistence: JSON files
* IDE: Visual Studio
* Version Control & Collaboration: GitHub

## Getting Started

To run this project locally on your machine, follow these steps:

1. Navigate to the source code folder: Open your terminal and change the directory to the project's source folder using the command: cd src/TaskFlow

2. Build and Run: Use the .NET CLI to compile and start the application using the command: dotnet run

3. Usage: Once the application is running, interact with the main menu in the console by selecting options 1 through 6 to manage the tasks.
